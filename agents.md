# Capital — правила для AI-агентов

Финансовый трекер (PWA + Capacitor Android). Стек: Vanilla JS, Tailwind, Firebase.

## Запуск и проверка
- `npm run dev` — локальный сервер
- `npm run lint -- --fix` — **запускай после изменений и исправляй ошибки до завершения задачи**
- `npx cap sync android` — синхронизация перед сборкой APK

## Архитектурные ограничения
- **Оффлайн-first**: изменения сначала в `window.Cache` → мгновенный UI → фоновая запись в Firestore.
- **Firestore только через `getUserCol(tableName)`** из `core.js`. Прямые пути к коллекциям запрещены.
- **Финансовые параметры** (лимиты, пороги, правила категоризации) — только в `default-rules.js`, не в обработчиках.
- **UI на русском**, переменные/комментарии/функции — на английском.
- **Без emoji** в служебном UI; иконки — только Lucide (`iconsSVG.js`).

## Ключевые модули
- `core.js` — Firebase, `window.Cache`, утилиты, `getUserCol`
- `budget.js` — лимиты, распределение дохода, календарь счетов
- `transactions.js` — реестр операций, фильтры, модалки трат
- `statement-parser.js` — парсинг выписок РФ (Сбер, Т-Банк, Яндекс Пэй, Озон, ВТБ)
- `apk-features.js` — нативная интеграция Android (веб-код сюда не класть)
- `investments.js` — вклады, брокерский портфель, MOEX ISS API
- `backup-manager.js` — экспорт/импорт, инспектор дубликатов
- `ui-tools.js` — модалки, тосты, дропдауны, общие UI-примитивы

## Ловушки, не видимые из кода
- `Cache.transactions` — массив **месяцев** (`[{ id: '2026-10', items: [...] }]`), не плоский список операций.
- Если задан `Cache.family?.id` → путь `families/{familyId}/…`, иначе → `users/{userId}/…`.
- **Не заменяй `Cache` целиком** — только мутируй поля, иначе слетят подписки UI.
- При ошибке записи в Firestore — откат локального изменения + тост.

## Коммуникация
- Вопрос или идея → режим обсуждения: ответь текстом, **не меняй код**.
- Прямая команда реализовать → действуй. Если при интеграции нужен рефакторинг соседних модулей — кратко опиши изменения.
